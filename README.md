💸 SpendWise - Smart Expense Tracker

SpendWise is a lightweight and intuitive expense manager designed to help users
take control of their finances. Track your daily spending, set budgets, and
visualize your financial habits with ease.

🌟 Key Features

  - 📝 Quick Logging: Add income and expenses in seconds with a simple, clean
    interface.
  - 📊 Visual Analytics: Understand your spending patterns through interactive
    pie charts and bar graphs.
  - 📂 Smart Categorization: Group expenses into categories like Food, Travel,
    Shopping, and Bills.
  - 📅 History & Filtering: View your transaction history by day, week, or month.
  - 💰 Budgeting: Set monthly limits for different categories to prevent
    overspending.
  - 🔒 Data Privacy: Your financial data stays on your device (Local Storage).

🛠️ Technical Details

  - Frontend: Flutter & Dart
  - State Management: Provider / Riverpod
  - Local Database: Hive / SQLite (for offline persistence)
  - Charts: fl_chart or syncfusion_flutter_charts
  - UI Components: Material Design 3

🚀 Installation & Setup

1.  Clone the repo
    git clone https://github.com/suhani2810/spend_wise.git
2.  Install packages
    flutter pub get
3.  Run the app
    flutter run
